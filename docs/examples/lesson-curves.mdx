# 贝塞尔与圆弧 · 实时示例

对应 `bezier-cubic.html`（`bezierCurveTo` 三次贝塞尔）、`bezier-quadratic.html`（`quadraticCurveTo`
二次贝塞尔）与 `arc.html`（`context.arc` 部分圆弧）。ice-render 用同一个 `ICEPolyLine` 表达曲线——
`curveType: 'quadratic' | 'cubic'` 时，`points` 的前 3 / 4 个点被解释为「起点 + 控制点 + 终点」。

## 三次贝塞尔曲线

`bezierCurveTo(cp1x,cp1y,cp2x,cp2y,x,y)` → `points: [起点, 控制点1, 控制点2, 终点]`，`curveType:'cubic'`。

<IceCanvas
  height={260}
  setup={(ICE, ice) => {
    const { ICEPolyLine } = ICE;
    ice.addChild(new ICEPolyLine({
      points: [[60, 220], [200, 40], [340, 40], [480, 220]],
      curveType: 'cubic', stroke: true, lineWidth: 3,
      style: { strokeStyle: '#4f8cff' },
    }));
  }}
/>

```jsx title="三次贝塞尔" {1-6}
ice.addChild(new ICEPolyLine({
  points: [[60, 220], [200, 40], [340, 40], [480, 220]], // 起/控1/控2/终
  curveType: 'cubic', stroke: true, lineWidth: 3,
  style: { strokeStyle: '#4f8cff' },
}));
```

## 部分圆弧

`arc.html` 用 `context.arc(origin, 100, 0, Math.PI/4, true)` 画了一段不闭合的圆弧。下面沿圆弧
采样点集、用 `ICEPolyLine` 连成开放曲线，效果完全一致（引擎也提供 `ICEEllipse` 的
`startAngle` / `endAngle` 直接用 `ctx.ellipse` 画弧，但会自带闭合的两条半径，这里用采样更贴近原 demo）。

<IceCanvas
  height={260}
  setup={(ICE, ice) => {
    const { ICEPolyLine } = ICE;
    const arcPoints = (cx, cy, r, a0, a1, steps) => {
      const pts = [];
      for (let i = 0; i <= steps; i++) {
        const a = a0 + (a1 - a0) * (i / steps);
        pts.push([cx + r * Math.cos(a), cy + r * Math.sin(a)]);
      }
      return pts;
    };
    ice.addChild(new ICEPolyLine({
      points: arcPoints(260, 140, 100, 0, Math.PI / 4, 48),
      stroke: true, lineWidth: 3,
      style: { strokeStyle: '#22c55e' },
    }));
  }}
/>

```jsx title="采样圆弧" {2-8}
const arcPoints = (cx, cy, r, a0, a1, steps) => {
  const pts = [];
  for (let i = 0; i <= steps; i++) {
    const a = a0 + (a1 - a0) * (i / steps);
    pts.push([cx + r * Math.cos(a), cy + r * Math.sin(a)]);
  }
  return pts;
};
ice.addChild(new ICEPolyLine({ points: arcPoints(260, 140, 100, 0, Math.PI / 4, 48),
  stroke: true, lineWidth: 3, style: { strokeStyle: '#22c55e' } }));
```

> `path-basic.html` 演示的是「直接传一段 `Path2D` 字符串」这种即时模式写法。ice-render 是**保留模式**
> 引擎，不暴露原始 `Path2D` 字符串——所有路径都用图元组件（或其 `dots` / `points`）表达，好处是
> 自动获得命中检测、拖动、序列化与局部重绘。
