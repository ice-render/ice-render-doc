# 形状与多边形 · 实时示例

这一组对应 `ice-render-lesson/tests/basic/` 里的 `shapes.html`（用 `context.path` 手画椭圆）与
`artTo.html`（用 `arcTo` 手画圆角矩形）。在 ice-render 里，**不用手算路径点、也不用记 `arcTo`
参数**，直接用对应的图元组件即可。

## 基础形状

`ICEEllipse` / `ICERect` / `ICECircle` 三个图元覆盖了绝大多数「画一个形状」的需求，
它们都继承自 `ICEPath`，天生支持填充、描边、渐变与拖动。

<IceCanvas
  height={240}
  setup={(ICE, ice) => {
    const { ICERect, ICECircle, ICEEllipse } = ICE;
    // 椭圆（对应 shapes.html 里手画的 path 椭圆）
    ice.addChild(
      new ICEEllipse({
        left: 40, top: 40, width: 200, height: 110,
        fill: true, stroke: true,
        style: { fillStyle: '#4f8cff', strokeStyle: '#1f4fb0', lineWidth: 2 },
      })
    );
    // 矩形
    ice.addChild(
      new ICERect({
        left: 280, top: 40, width: 160, height: 110,
        fill: true, stroke: true,
        style: { fillStyle: '#ff7a59', strokeStyle: '#c2410c', lineWidth: 2 },
      })
    );
    // 正圆
    ice.addChild(
      new ICECircle({
        left: 500, top: 40, radius: 55,
        fill: true, stroke: true,
        style: { fillStyle: '#22c55e', strokeStyle: '#15803d', lineWidth: 2 },
      })
    );
  }}
/>

```jsx title="基础形状" {4-20}
const { ICERect, ICECircle, ICEEllipse } = ICE;
ice.addChild(new ICEEllipse({ left: 40, top: 40, width: 200, height: 110, fill: true, stroke: true,
  style: { fillStyle: '#4f8cff', strokeStyle: '#1f4fb0', lineWidth: 2 } }));
ice.addChild(new ICERect({ left: 280, top: 40, width: 160, height: 110, fill: true, stroke: true,
  style: { fillStyle: '#ff7a59', strokeStyle: '#c2410c', lineWidth: 2 } }));
ice.addChild(new ICECircle({ left: 500, top: 40, radius: 55, fill: true, stroke: true,
  style: { fillStyle: '#22c55e', strokeStyle: '#15803d', lineWidth: 2 } }));
```

## 圆角矩形

`artTo.html` 用 12 个控制点 + `arcTo` 画了一个「四角圆化到一半」的矩形。ice-render 里只需给
`ICERect` 一个 `radius` 属性——引擎内部用 `arcTo` 实现，并自动把 `radius` 钳制到 `min(w/2, h/2)`，
所以 `radius` 给多大都不会溢出。

<IceCanvas
  height={260}
  setup={(ICE, ice) => {
    const { ICERect } = ICE;
    ice.addChild(
      new ICERect({
        left: 280, top: 30, width: 200, height: 200,
        radius: 100, // 圆化到一半 → 两端变成半圆（与 artTo.html 的 cornerRadius=200 等价）
        fill: false, stroke: true,
        style: { strokeStyle: '#ff0000', lineWidth: 3 },
      })
    );
  }}
/>

```jsx title="圆角矩形" {2-7}
// radius 会被钳制到 min(width/2, height/2)，所以 radius≥100 都得到同样的「全圆角」效果
ice.addChild(new ICERect({
  left: 280, top: 30, width: 200, height: 200, radius: 100,
  fill: false, stroke: true,
  style: { strokeStyle: '#ff0000', lineWidth: 3 },
}));
```

## 星形与正 N 边形

`ICEStar`（正 N 角星）与 `ICEIsogon`（正 N 边形）是 `ICEDotPath` 的具体子类，内部用极坐标公式
算出顶点，外部只需要给 `spikes` / `edges`。

<IceCanvas
  height={200}
  setup={(ICE, ice) => {
    const { ICEStar, ICEIsogon } = ICE;
    ice.addChild(
      new ICEStar({
        left: 60, top: 30, outerRadius: 70, innerRadius: 30, spikes: 5,
        fill: true, stroke: true,
        style: { fillStyle: '#f59e0b', strokeStyle: '#b45309', lineWidth: 2 },
      })
    );
    ice.addChild(
      new ICEIsogon({
        left: 280, top: 30, radius: 70, edges: 6, startAngle: 90,
        fill: true, stroke: true,
        style: { fillStyle: '#a855f7', strokeStyle: '#7e22ce', lineWidth: 2 },
      })
    );
    ice.addChild(
      new ICEIsogon({
        left: 500, top: 30, radius: 70, edges: 3, startAngle: 90,
        fill: true, stroke: true,
        style: { fillStyle: '#06b6d4', strokeStyle: '#0e7490', lineWidth: 2 },
      })
    );
  }}
/>

```jsx title="星形 / 正 N 边形" {1-9}
const { ICEStar, ICEIsogon } = ICE;
ice.addChild(new ICEStar({ left: 60, top: 30, outerRadius: 70, innerRadius: 30, spikes: 5,
  fill: true, stroke: true, style: { fillStyle: '#f59e0b', strokeStyle: '#b45309', lineWidth: 2 } }));
ice.addChild(new ICEIsogon({ left: 280, top: 30, radius: 70, edges: 6, startAngle: 90,
  fill: true, stroke: true, style: { fillStyle: '#a855f7', strokeStyle: '#7e22ce', lineWidth: 2 } }));
```

把 `edges` 改成 4 / 5 / 8，刷新即可看到不同的正多边形——这些图元都可直接 `registerType`
后序列化进设计器（参见 [基于内核二次开发](/docs/advanced/secondary-development)）。
