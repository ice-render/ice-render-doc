两套 API 与 options：on/off/once 与 addEventListener

组件上这两套是同一个实现、两种参数形状：on(name, fn, scope?, options?) 与 addEventListener(type, fn, options?) 共用同一份注册/摘除逻辑，once 是监听记录上的标记 （所以 off / removeEventListener 用**同一个身份**就能摘掉）。 下面每个按钮都会把"引擎里发生了什么"打到日志里；passive 那一条还会演示 "在 passive 监听器里调 preventDefault() 不生效"，并在控制台提醒一次。
