插件机制：PluginHost 三层注册点

PluginHost 提供「组件 / 渲染 / 交互工具」三层注册点：components 声明自定义图元 （自动 registerType，获得序列化 typeId 反查）；render 每帧在世界坐标下叠加绘制； tools 按 match(component) 挂交互工具。ice.use(plugin) 幂等， unuse 撤销渲染/工具（类型注册保留）。下方网格插件可开关。
