事件机制：ICEEventTarget + EventBus

Canvas 内部没有 DOM 事件，引擎用 ICEEventTarget（模仿 W3C EventTarget，别名 addEventListener/on/off）给每个组件挂事件，原生 DOM 事件经 DOMEventDispatcher 转发成 ICEEvent 后派发到对应组件。click / mousedown / mouseup 是一等公民组件事件；但引擎不派发 mouseenter/mouseleave——下面悬停高亮演示的是引擎原生做法：监听总线 mousemove + ice.hitTest() 自己判定命中组件。
