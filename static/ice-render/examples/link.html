Link 机制：插槽（ICELinkSlot）+ 连线（ICEPolyLine）

可连接组件（state.linkable:true）在运行时会由 ICELinkSlotManager 动态挂上 4 边中点 + 中心的 ICELinkSlot。拖动连线端点手柄（linkEditable）可改连接关系， 连线本身按 links 数据模型绑定目标组件，目标移动时自动跟随。下方两个框可拖动，连线跟随。

连线：已连接（box1.R → box2.L）
// 连线数据模型
links: {
  R: { id:'box1', position:'L' }  // 自身 R 槽 → box1 的 L 槽
}
