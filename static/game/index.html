画布游戏厅：用 ICE 家族的渲染引擎与画布控件做的单页小游戏合集 —— 打砖块、ICE Arcade 掌机、Windows XP 桌面。浏览器打开即玩，无需服务端、无需安装。

小游戏

  • 打砖块 —— 挡板接球，清空所有砖块 —— 掉球扣命，三命用完结束

整机展厅

  • ICE Arcade 掌机 —— 一台掌机，四张卡带 —— 开机先跑 BIOS 自检再选卡带
  • Windows XP 桌面 —— 会自己开机的画布桌面：开机自检 → 欢迎屏 → 桌面

技术栈

页面与控件全部由 ICE 家族在 HTML5 Canvas 上绘制，画面里没有任何位图资源。

  • ice-render：Canvas 2D 渲染引擎（家族的地基）
  • ice-web-components：画布原生 UI 控件库
  • @damoqiongqiu/ice-chart：交互式图表库

源码与文档：github.com/ice-render
